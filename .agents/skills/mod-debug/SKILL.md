# mod-debug

入力は版一覧、side、再現手順、加工前後の状態、秘匿情報を除いたログ。出力は根拠のある原因、最小修正、再現条件での再検証結果。

最初の原因例外と実際に読み込まれた版を確認し、[対応構成](../../../docs/compatibility.md)と照合する。設定／生成データ／通常JAR／dev classpathを区別し、一度に一つの仮説を検証する。client参照による専用サーバー失敗や、別版API／KFF metadata不整合を無関係な更新で隠さない。

保存・素材消費の調査は新規／コピーのワールドとインベントリで行う。修正前に再現を記録し、修正後は同じ条件と関連する失敗条件を確認する。[検証手順](../../../docs/verification.md)に構成・手順・観測結果を残す。
